Ready: press Start exploration", then click Start exploration on the SAME page.

Reset stops/disarms the drive, cancels navigation and planner work, clears
stuck pending/arming flags, failure cooldowns, visits and reverse recovery
history. Delayed replies from old attempts are cancelled and cannot change
new attempt state. Start waits until old actions finish cancellation.

Readiness requires fresh confirmed DISARMED telemetry, zero applied duty,
vehicle speed below 0.02 m/s, sensor health, fresh map and available navigation
services. Real sensor faults or an unresponsive navigation service remain
visible; Reset does not bypass them. This is a navigation-session reset, not
a Pi reboot, SLAM map reset or hardware fault override.

Root cause fixed: halt() did not clear pending. Old action callbacks also
cleared pending/plan handles before checking session generation, allowing
late results to overwrite a later attempt. Action response/result work is
now tracked through cancellation and generation checks precede mutations.
Exceptions from action requests/results now halt cleanly.

includes pending planner stop, late acceptance/cancellation, stale navigation
and planner results, repeated explicit reset/start, fresh stop confirmation,
sensor-fault gating, reset button/authentication and Start button gating.
